# Tecnologías de Microprocesamiento

Este repositorio contiene los trabajos prácticos y laboratorios de la asignatura **Tecnologías de Microprocesamiento** (Ingeniería Mecatrónica).  
Durante el semestre se desarrollarán ejercicios y proyectos en **lenguaje ensamblador (ASM)** para el microcontrolador **ATmega328P**, junto con prácticas de integración con diferentes periféricos y dispositivos.

---

## 📂 Contenido
- **Laboratorios**  
  Carpeta destinada a almacenar los distintos laboratorios realizados durante el curso.  

- **Trabajo-Matriz**  
  Desarrollo de prácticas con la matriz de LEDs. 

---

## 🎯 Objetivo
El propósito de este repositorio es centralizar el material trabajado en clase y en el laboratorio, fomentando el uso de GitHub como herramienta de **versionado, trazabilidad y documentación** de los proyectos.
